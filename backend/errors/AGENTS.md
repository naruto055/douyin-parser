# AGENTS.md

本文件适用于 `backend/errors/`，聚焦错误模型和错误码。

本文中跨模块引用使用仓库根路径，例如 `backend/tests/...`。

## 1. 模块职责

- `AppError.js`：业务可预期异常与非业务异常的统一表达。
- `errorCodes.js`：项目内可复用错误码常量。

## 2. 设计约束

- 新增错误场景优先复用已有错误码；确需新增时同步更新 `backend/docs/API.md`。
- 业务可预期异常默认由全局错误处理中间件转换为 HTTP 200 + 业务错误码。
- 参数错误、限流、未知系统异常等非业务异常应保留对应 HTTP 状态语义。
- 不在业务代码中散落未登记的错误码字符串。

## 3. 测试建议

- 错误码或 `AppError` 行为变化需覆盖路由层响应测试。
- 统一响应结构变化需关注 `backend/tests/response.test.js`。

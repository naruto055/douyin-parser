# AGENTS.md

本文件适用于 `backend/docs/`，聚焦后端接口文档维护。

本文中本模块文件使用相对当前目录的写法；跨模块引用使用仓库根路径。

## 1. 模块职责

- `API.md`：后端 REST、下载、AI 普通对话和 SSE 流式接口契约说明。

## 2. 文档约束

- 接口文档必须以当前实现为准，不记录尚未实现的接口或字段。
- 修改请求参数、响应字段、错误码、限流规则、SSE 事件时，同步更新 `API.md`。
- 示例中的链接、密钥和模型配置只能使用占位值，不写真实凭据。
- 普通 JSON、文件下载、SSE 三类响应要分开描述，避免误导调用方。

## 3. 验证建议

- 文档-only 变更至少人工核对标题层级、路径和示例格式。
- 接口契约变化应结合对应路由/服务测试验证。
